## 🛠️ Local Development & Build

### 1. Prerequisites
* Node.js 18.17+ or Node.js 20+
* npm or pnpm

### 2. Installation
```bash
npm install
```

### 3. Local Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Production Build & Static Generation
```bash
npm run build
npm run start
```

## ☁️ Vercel Deployment Instructions

Deploying to Vercel requires zero complex setup:

### Method 1: Using the Vercel CLI
```bash
npm i -g vercel
vercel
```

### Method 2: GitHub Repository Link
1. Push this codebase to your GitHub account (`https://github.com/neeravjain91-jpg/Portfolio` or a new repository).
2. Go to [vercel.com/new](https://vercel.com/new).
3. Import the repository.
4. Framework Preset will automatically detect **Next.js**.
5. Click **Deploy**.
