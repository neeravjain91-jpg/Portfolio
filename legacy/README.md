# Legacy Portfolio Archive (Vite + Express Prototype)

This directory preserves the historical development prototype of the portfolio:
* `legacy/frontend/`: Initial React 19 / Vite single-page application.
* `legacy/backend/`: Initial Node.js Express API.

### Authoritative Production Implementation
The authoritative production version of this repository is the **Next.js 14 App Router** application located at the root of this repository (`/`), featuring static site generation (SSG), TypeScript, Tailwind CSS, verified live deployments, and 14 prerendered routes.
